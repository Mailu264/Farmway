# Как работать с инвентарем

Эта инструкция для человека, который настраивает UI и предметы в Unity. Код трогать не нужно.

---

## Общая идея

Инвентарь состоит из трех частей:

```
ItemsConfig          - список всех предметов в игре
InventoryView        - окно инвентаря
InventorySlotView    - одна ячейка инвентаря
InventoryDragView    - картинка предмета, которая летит за мышкой при перетаскивании
```

Что важно:

- `InventoryView` показывает окно инвентаря.
- `InventorySlotView` показывает один слот: иконку предмета и количество.
- `InventoryDragView` показывает предмет во время перетаскивания.
- `ItemsConfig` хранит настройки предметов: иконка, название, размер стака.

Логика инвентаря живет в коде. В Unity нужно только правильно настроить ссылки.

---

## Что можно менять

Можно:

- двигать, растягивать и стилизовать окно инвентаря;
- менять фон окна;
- менять размер и расположение слотов;
- менять картинки, цвета, шрифты;
- добавлять предметы в `ItemsConfig`;
- менять иконки предметов;
- менять `MaxStackSize`;
- включать или выключать `IsStackable`.

Нельзя без программиста:

- удалять компоненты `InventoryView`, `InventorySlotView`, `InventoryDragView`;
- удалять список слотов из `InventoryView`;
- менять порядок слотов в списке, если непонятно зачем;
- удалять `EventSystem` со сцены;
- удалять `GraphicRaycaster` с Canvas;
- выключать `Raycast Target` у фона слота.

---

## Настройка ItemsConfig

Файл конфига лежит тут:

```
Assets/_Data/Items/ItemsConfig.asset
```

В нем есть список `Items`.

Каждый элемент списка это один предмет:

| Поле | Что значит |
|---|---|
| `ItemId` | уникальный id предмета |
| `ItemType` | тип предмета |
| `Icon` | картинка предмета |
| `Name` | имя предмета |
| `MaxStackSize` | сколько штук помещается в один слот |
| `IsStackable` | можно ли складывать предмет в стак |

Пример:

```
ItemId: Item1
ItemType: Plant
Icon: картинка морковки
Name: Carrot
MaxStackSize: 20
IsStackable: true
```

Если предмет не должен стакаться, например инструмент:

```
ItemId: Item2
ItemType: Tool
Icon: картинка топора
Name: Axe
MaxStackSize: 1
IsStackable: false
```

Правила:

- Не используй `ItemId.None` для настоящего предмета.
- У двух предметов не должен быть одинаковый `ItemId`.
- Если `IsStackable = false`, ставь `MaxStackSize = 1`.
- Если `Icon` пустой, в инвентаре не будет картинки.

## Настройка окна InventoryView

На объекте окна инвентаря должен висеть компонент:

```
InventoryView
```

У него есть поля:

| Поле | Что туда поставить |
|---|---|
| `Drag View` | объект с компонентом `InventoryDragView` |
| `Inventory Slots` | список всех слотов инвентаря |

`Inventory Slots` заполняется по порядку:

```
0  - первый слот
1  - второй слот
2  - третий слот
...
23 - двадцать четвертый слот
```

Сейчас код создает 24 слота. Значит в `Inventory Slots` тоже должно быть 24 элемента.

Если слотов в списке меньше, часть предметов не будет видна.

---

## Настройка слота InventorySlotView

На prefab или объекте слота должен висеть компонент:

```
InventorySlotView
```

У него есть поля:

| Поле | Что туда поставить |
|---|---|
| `Icon Placement` | UI `Image`, где показывается иконка предмета |
| `Count` | TMP текст с количеством |

Обычно структура слота такая:

```
Slot
├── Background Image
├── Icon Image
└── Count Text
```

Важно:

- У `Slot` или его фоновой картинки должен быть включен `Raycast Target`.
- У `Icon Image` можно выключить `Raycast Target`, чтобы он не мешал перетаскиванию.
- У `Count Text` можно выключить `Raycast Target`.
- `Icon Placement` должен ссылаться именно на картинку предмета, не на фон слота.
- `Count` должен ссылаться на текст количества.

Пустой слот выглядит пустым, но его фон все равно должен принимать мышку. Иначе в пустой слот нельзя будет перетащить предмет.

---

## Настройка InventoryDragView

`InventoryDragView` это отдельный объект для картинки, которая появляется при перетаскивании предмета.

Он должен быть внутри UI окна или Canvas, но не внутри конкретного слота.

Пример:

```
Inventory
├── Slots
│   ├── Slot 0
│   ├── Slot 1
│   └── ...
└── InventoryDragView
    ├── Icon
    └── Count
```

На объекте `InventoryDragView` должен висеть компонент:

```
InventoryDragView
```

У него есть поля:

| Поле | Что туда поставить |
|---|---|
| `Icon` | UI `Image`, который показывает иконку перетаскиваемого предмета |
| `Count` | TMP текст количества |

Важно:

- `InventoryDragView` должен быть назначен в поле `Drag View` у `InventoryView`.
- У `Icon` и `Count` должен быть выключен `Raycast Target`.
- Если забыть назначить `Drag View`, перетаскивание визуально работать не будет.

---

## Как работает перетаскивание

Когда игрок тащит предмет:

1. Слот сообщает презентеру: "меня начали тащить".
2. `InventoryDragView` показывает иконку и количество.
3. Иконка летит за мышкой.
4. Оригинальный слот временно прячется.
5. Если предмет отпустили на другой слот:
   - если слот пустой, предмет переезжает туда;
   - если там такой же предмет и есть место в стаке, предметы объединяются;
   - если там другой предмет, слоты меняются местами.
6. Если отпустить не на слот, предмет возвращается назад.

## Частые проблемы

**Предмет не перетаскивается**

Проверь:

- на сцене есть `EventSystem`;
- на Canvas есть `GraphicRaycaster`;
- у слота или его фона включен `Raycast Target`;
- слот не пустой.

**В пустой слот нельзя перетащить предмет**

Скорее всего у пустого слота нет активной картинки с `Raycast Target`.

Решение: у фоновой картинки слота включи `Raycast Target`.

**При перетаскивании иконка закрывает слот и drop не работает**

У `InventoryDragView/Icon` и `InventoryDragView/Count` выключи `Raycast Target`.

**Количество не видно**

Проверь поле `Count` в `InventorySlotView` и `InventoryDragView`.

Количество показывается только если предметов больше 1.

**Иконка не показывается**

Проверь:

- у предмета в `ItemsConfig` заполнено поле `Icon`;
- в слоте заполнено поле `Icon Placement`;
- в drag view заполнено поле `Icon`.

**В консоли ошибка `Duplicate item id`**

В `ItemsConfig` два предмета имеют одинаковый `ItemId`. Нужно заменить один из них.

---

## Мини-чеклист перед запуском

Перед тем как нажимать Play:

- `ItemsConfig` заполнен.
- У каждого предмета есть уникальный `ItemId`.
- У каждого предмета есть `Icon`.
- `InventoryView` висит на окне инвентаря.
- В `InventoryView` назначен `Drag View`.
- В `InventoryView` заполнен список `Inventory Slots`.
- На каждом слоте есть `InventorySlotView`.
- В каждом слоте назначены `Icon Placement` и `Count`.
- На сцене есть `EventSystem`.
- На Canvas есть `GraphicRaycaster`.

Если все пункты выполнены, инвентарь должен отображаться и перетаскивание должно работать.
